An entry for the make.fun contest **One Sentence for a Traveler from 1800**:
explain the modern internet in a single sentence of at most 200 characters
to someone who has just stepped out of the year 1800.

## The sentence

> Imagine every printing press, post rider and library on Earth shrunk into one small glowing slate you carry, where any question you ask is answered by strangers before your tea cools.

The picture is built only from things the traveler already knows. The
printing press and the library stand for the world's stored knowledge, the
post rider for messages carried between distant people, and the slate —
the schoolroom writing board of 1800 — for the small glowing screen that
now holds all three at once. The closing detail, an answer arriving before
your tea cools, carries the one fact that would astonish 1800 most: the
speed of it.

## How it runs

`main.ts` is a dependency-free Node program. When run, it clears the
contents of the output directory (never the directory itself, which is a
mount point in the grader), then writes the sentence to `entry.txt` in
that directory with no trailing newline — 183 characters of UTF-8 text,
inside the contest's 1–200 character gate.
